Warcraft II Trigger Studio 1.44.0 - Short-Path Package
=====================================================
Extract W2TS144.zip normally. The archive uses the short W2TS144 root so Windows
Explorer stays well below the legacy path-length limit.

Start with Start_Trigger_Studio.bat.
Open Tools -> Custom Ability Engine to author abilities stored in the trigger sidecar.
Open Tools -> All Cards Trigger Engine to import all 418 source card rows and enable Human/Orc cross-faction producers.
Editable source is in W2TS144\src.
AUTO Attach + Start is enabled by default; manual Attach/Start/Stop remain available.
